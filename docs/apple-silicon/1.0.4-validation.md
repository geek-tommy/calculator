# 1.0.4 regression checks

The Mac Catalyst navigation uses an explicit control template with hover, pressed, selected, and keyboard focus states. It reconciles every menu item with the active application mode instead of depending on the legacy nested presenter. The selected item retains its selection styling; previously clicked items return to Normal. Calculator button feedback remains separately handled.

Converter startup normalizes neutral cultures to a specific culture before constructing RegionInfo, preserving the zh-Hans resource override. A prior diagnostic build reproduced Argument_InvalidNeutralRegionName for all 13 converter modes.

The packaged application's CI-only startup probe checks:

- All 13 converter modes, standard/scientific/programmer modes, and return navigation through NavigationView.SelectedItem.
- Exactly one selected menu item after each navigation.
- Each menu item's actual template enters PointerOver and Pressed, then restores its expected state and panel/border background brushes.
- Unit lists and selected units for every non-currency converter.
- 1 litre = 1000 millilitres, 1 metre = 100 centimetres, 1 degree Celsius = 33.8 degrees Fahrenheit. Unicode directional formatting is removed only by the test parser.
- Simplified Chinese resources, calculator button feedback, ARM64 architecture, signature integrity, and process startup.

These probes are enabled only by CI environment variables. They do not simulate physical mouse input, and opening the currency page does not verify live exchange-rate availability. Physical clicks, keyboard accessibility, and live currency refresh remain manual acceptance checks.
