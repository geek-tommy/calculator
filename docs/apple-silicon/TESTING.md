# Uno Calculator ARM — 个人测试版

这是基于 Uno Calculator 开源项目的社区测试构建，与上游官方发行版不同。
构建目标：Apple Silicon ARM64、Mac Catalyst；最低系统版本由打包后的 Info.plist 确定。
源码未完成 macOS 编译前，不应将此适配包当成已验证的应用。

生成的应用使用本地 ad-hoc 签名，没有 Apple Developer ID 签名及公证。
若 macOS 阻止打开，请先核对来源及 SHA256 校验值，再使用系统设置中的
“隐私与安全性 → 仍要打开”（若该选项可用）。不需要关闭系统整体安全保护。

安装：打开 DMG，把应用拖入 Applications；也可以解压应用 ZIP。
应用内保留 LICENSE / NOTICE.txt；部分功能如汇率更新需要联网。

## 人工验收

- 能启动、关闭并重新打开，窗口缩放、菜单及中文显示正常。
- 活动监视器中“种类”为 Apple，不依赖 Rosetta。
- 标准：12 + 34 = 46；0.1 + 0.2 = 0.3；1 ÷ 0 显示错误且能清除。
- 科学：2 + 3 × 4 = 14；角度模式 sin(30) = 0.5。
- 程序员：十进制 255 转为十六进制 FF、二进制 11111111。
- 单位：1 米 = 100 厘米；0 摄氏度 = 32 华氏度。
- 键盘输入、复制粘贴、历史记录和内存存取可用。
- 日期计算正确；汇率功能单独检查数据日期及联网失败处理。

自动流程检查编译、所有随包 Mach-O 文件为 ARM64、签名完整性，
以及在 ARM 构建机器上存活 12 秒的启动检查；不代表人工验收已通过。
